# Face_Attendance
A small face-recognition attendance application built while exploring computer vision and GUI development. This project is inspired by [https://www.youtube.com/watch?v=z_dbnYHAQYg&amp;t=427s], but is independently implemented and adapted using PyQt6 instead of Tkinter for the UI.

Note: The original Tutorial video uses Pillow convert captured frame into QImage image (for webcam in the first page)... but as I am using PyQt6 instead of Tkinter, I have used a workaround by converting it into jpeg file and giving jpeg file to QImage to be converted.
